# 一起走过的日常

把共同经历整理成一份适合分享的日常回忆。人名和具体地点做了省略，留下那些想起来会觉得温暖的小事。

## 从相识到熟悉

从第一次约会后的散步和爬山，到后来一起做饭、看动画，熟悉就在这些平常的相处里一点点发生。普通的周末，因为有了期待，也变得不太一样。

## 一起去看看

一起听现场演出、看展，也计划过几次旅行。路上的风景会慢慢淡去，但一起分享的惊喜、笑声和回程时聊过的话，还会留在记忆里。

## 把喜欢的事分享给彼此

从尝试滑冰和匹克球，到在家做拼豆、玩合作游戏，总能找到新的小事一起体验。也会认真准备生日惊喜，让对方知道自己一直被放在心上。

## 平常日子里的喜欢

一起做一顿饭、看完一部动画，或只是约好下次去哪儿，这些看起来普通的片段，最后都成了很舍不得忘记的回忆。
